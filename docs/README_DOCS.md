# Документация OilCoin

[Кампания, боссы и билды](CAMPAIGN.md) — новые правила PvE, сундуков за OIL и частичного сбора.

Все эти руководства доступны прямо на сайте в [разделе «Помощь»](/docs/), без входа в кошелёк. Используйте поиск, меню разделов и оглавление статьи; текст можно скачать или распечатать. Markdown-файлы остаются исходниками документации.

- [Вопросы и ответы](FAQ.md) — очередь, резерв, комиссии, улучшения, вход и ошибки.
- [Возможности](FEATURES.md) — реализованные функции и ограничения.
