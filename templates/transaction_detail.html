Как это влияет на экономику

{% if tx.type == 'transfer' %}

Отправитель платит {{ tx.amount }} OIL и комиссию {{ tx.fee }} OIL. Получатель получает {{ tx.amount }} OIL. Из комиссии {{ tx.burn }} OIL удаляется из обращения; остальное получает майнер после подтверждения блока.

Новые OIL выпускаются как вознаграждение за доказательство работы. Эта операция увеличивает общую эмиссию в пределах лимита сети.

Майнер получает часть комиссий включённых в блок переводов. Это перераспределение существующих монет, а не дополнительная эмиссия.
